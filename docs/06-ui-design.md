# 06. UI/画面設計

Asana 風のシンプルで視覚的なタスク管理 UI。対象は学生のため、締切・優先度・進捗が一目でわかる設計とする。

## 1. 画面一覧

| 画面 | パス | 説明 |
|---|---|---|
| ダッシュボード | `/` | 今日・今週のタスク、期限切れ、プロジェクト進捗を表示 |
| タスク一覧 | `/tasks` | すべてのタスクをリスト/ボード表示 |
| タスク作成 | `/tasks/new` | 新規タスク作成フォーム |
| タスク詳細 | `/tasks/:id` | サイドパネル or ページで詳細編集 |
| 科目一覧 | `/subjects` | 科目の管理 |
| プロジェクト一覧 | `/projects` | 研究プロジェクトの管理 |
| プロジェクト詳細 | `/projects/:id` | プロジェクト詳細 + 進捗ログ |
| カレンダー | `/calendar` | 締切をカレンダー表示 |

┌──────────────────────────────────────────────────────────┐

├──────────┬───────────────────────────────────────────────┤
│          │                                               │
│  サイド  │              メインコンテンツ                  │
│  ナビ    │                                               │
│          │                                               │
│          │                                               │
└──────────┴───────────────────────────────────────────────┘
```

- ヘッダー：ロゴ + グローバルナビ

- メイン：タスクリスト or カンバン or カレンダー

## 4. タスク一覧

### リストビュー

```
┌────────────────────────────────────────────────────────────┐
│ + 新規タスク                                                │
├────────────────────────────────────────────────────────────┤
│ □ 制御工学 演習問題          4/7 月  中  科目:制御工学      │
│ □ 情報工学 レポート          4/9 水  高  科目:情報工学      │
│ ■ 歩行ロボット モータ測定    4/10 木 高  プロジェクト       │
│ □ 英語 リスニング            毎週火   低                   │

- チェックボックスで完了/未完了切り替え
- 色タグで科目/プロジェクトを区別
- タップで詳細パネルを開く

## 9. 状態管理

- `useTasks()`: タスク一覧・CRUD
- `useSubjects()`: 科目一覧
- `useProjects()`: プロジェクト一覧・進捗
- `useDashboard()`: ダッシュボード集計

`composables/` に Pinia ストア or useState ベースで実装。

## 10. レスポンシブ

- デスクトップ：サイドバー常時表示 + カンバンビュー
- タブレット：サイドバー折りたたみ
- スマホ：ボトムナビ or ハンバーガーメニュー + リストビュー優先
